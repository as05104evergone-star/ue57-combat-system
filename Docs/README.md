### 4.2 文档自身的更新规则

1. **不删历史**：过时的文档移入 `归档/`，文件头加 3 行说明（何时写的、为何过时、现在看哪份），不要直接删除。

6. **交接时先更新交接文档 v2，再写新的实施手册** —— 手册引用 v2，不重复抄资产事实。
7. **审查报告不长期累积**：每轮大改后新开一份 `审查/NN-xxx.md`，把上一份的结论合并进正式文档后即可归档。
