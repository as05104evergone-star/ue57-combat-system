## 8. 数值表 → DataTable 落地规范（W5 交付的关键工程约定）

- 行结构统一：**`S_GameParam { Key: Name; Value: float; Unit: Name; Note: Text }`**
- 表名与键空间：`DT_Karma`(`karma.*`) / `DT_Combat`(`combat.*`,`player.*`,`weapon.*`) / `DT_Skill`(`qi.*`,`passive.*`) / `DT_Enemy`(`enemy.*`) / `DT_Boss`(`boss.*`) / `DT_Level`(`level*`) / `DT_Rating`(`rating.*`) / `DT_Gun`(`gun.*`) / `DT_Prop`(`prop.*`)
- 取值统一走取数函数，**蓝图内禁止出现裸数字**（策划书 0.5 节的硬要求）
  - **v2 注（2026-10-19）**：实际实现是**按表拆的两个函数** `BPFL_GameParams.GetCombatParam(Table, Key)` / `GetEnemyParam(Table, Key)`，**不是**通用的 `BPFL_GetParam(DataTable, Key)`。原因：`Get Data Table Row` 的 `Table` 引脚只能接**具体数据表资产的硬引用**，不能接任意 DataTable 变量（否则编译红字，见 `BP_NPC受击与血量死亡实现手册(已完成).md` 附录 C-13）。以后新增表域时照此再拆一个函数（如 `GetBossParam`），不要试图做通用版。
- 导出方式：Excel 每张子表按"程序参数键(Key) / 基准数值 / 单位 / 设计意图"四列另存 CSV；注意百分数按字面存储（`30` 表示 30%），程序读取后按单位换算（数值表 00 表 B8）
- **绿底公式格禁止手工覆盖**（00 表 D7）：K-15/K-21 随 K-01、G-04 = G-02×G-03、S-04 = S-02×S-03、S-13 = S-01÷S-12、S-14 = S-02÷S-12
